# 🤖 Desafio: Criando um Copiloto com Fluxo de Conversa Personalizado

## 🎯 Objetivo
Este projeto foi desenvolvido como parte do desafio da DIO para criar um **Copiloto com fluxo de conversa personalizado** no **Microsoft Copilot Studio**.

## ✅ O que foi feito

- Criei um agente chamado **Agente da DIO**, com foco em ajudar usuários a entenderem e navegarem pela documentação do Microsoft Copilot Studio.
- Configurei um **fluxo de conversa personalizado**, com base em perguntas frequentes e dúvidas comuns de iniciantes na plataforma.
- Alimentei o agente com instruções claras e usei gatilhos simples para facilitar o uso.

## 🛠️ Funcionalidades

- Responde a perguntas como:
  - "O que é o Copilot Studio?"
  - "Como criar um novo agente?"
  - "Para que servem os fluxos?"
- Personalização do comportamento do agente para falar sempre como **"Agente da DIO"**.
- Mensagens com linguagem informal e acolhedora, voltada para quem está começando.

## 🧪 Testes realizados

- Realizei testes no ambiente do Copilot Studio simulando interações com usuários reais.
- Ajustei os gatilhos para reconhecer diferentes formas de perguntar a mesma coisa.
- Validei o fluxo para garantir respostas completas e claras.

## 🧠 Aprendizado

Durante a criação do agente, aprendi a:

- Utilizar a interface do Copilot Studio para criar e configurar agentes.
- Criar fluxos de conversa personalizados com tópicos e variáveis.
- Aplicar boas práticas de UX conversacional, tornando a interação simples e objetiva.

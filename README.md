# 🧠 Desafio Copilot Studio - DIO

## ✨ Agente criado: **Agente da Oxe Milhas**

## ✅ O que foi feito

Neste desafio, criei meu primeiro agente no **Microsoft Copilot Studio**, com o objetivo de oferecer informações úteis sobre **programas de milhas aéreas**. Para isso, alimentei o agente com dados de sites especializados, incluindo:

- O que são milhas e pontos;
- Como acumular milhas;
- Funcionamento dos programas de fidelidade;
- Dicas de uso estratégico das milhas.

## ⚙️ Configurações realizadas

- Criação de **tópicos personalizados** com gatilhos como:  
  `"o que são milhas"`, `"como acumular milhas"`, `"como usar milhas"`, entre outros.
- Definição de **respostas detalhadas e didáticas** para cada pergunta.
- Organização dos fluxos para facilitar a interação com o usuário.

## 🧪 Testes realizados

- Simulei diversas interações no ambiente do Copilot Studio.
- Ajustei os gatilhos para aceitar variações de linguagem natural.
- Verifiquei se o fluxo de respostas estava funcionando corretamente.

## 🚀 Aprendizado

Com este desafio, aprendi a:

- Criar agentes personalizados usando o **Microsoft Copilot Studio**;
- Utilizar tópicos e gatilhos para mapear intenções do usuário;
- Testar e ajustar fluxos de conversação;
- Aplicar um tema prático (milhas aéreas) com foco em usabilidade.
